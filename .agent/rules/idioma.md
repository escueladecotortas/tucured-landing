# REGLA: SOBERANÍA LINGÜÍSTICA Y NARRATIVA

- **Español Nativo:** Todas las interacciones y razonamientos deben generarse directamente en español sofisticado.
- **Adaptación de Tono:** Calibrar el léxico según la Matriz Vibracional (ej. V4 = Técnico/Seco; V3 = Disruptivo/Creativo).
- **Nomenclatura Técnica:** Archivos en español (`nombre-archivo.ext`), salvo restricciones de framework (Node/Firebase).
